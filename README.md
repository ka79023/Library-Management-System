# Library Management System

A Java desktop application for managing library books, members, and borrowing activities. Developed as a university team project, it provides graphical interfaces for members and librarians.

## Features

- Add, remove, and search for books.
- Register members and search by member ID.
- Borrow and return books with borrowing-limit checks.
- View available books and a member’s borrowed books.
- Support different book categories: fiction, novels, romantic books, and study books.
- Save and load library records using local files.

## Technologies

| Technology | Purpose |
| --- | --- |
| Java | Application logic and object-oriented programming |
| Java Swing | Desktop graphical interfaces |
| Custom Linked Lists | Managing books and members |
| Java Serialization | Saving and loading library records |
| Apache NetBeans | Development and GUI design |

## Getting Started

1. Clone this repository or download and extract its ZIP archive.
2. Open the project in Apache NetBeans.
3. Select a compatible JDK. The project configuration targets JDK 24.
4. Right-click the project and select **Clean and Build**.
5. Open `src/phasetwo/firstFrame.java` and select **Run File**.
6. Choose **Member** or **Librarian** from the welcome screen.

Use the application's **Exit** button to save the current records before closing.

## Project Scope

This is a local desktop application developed for academic purposes. It demonstrates object-oriented programming, custom linked lists, GUI interactions, and file persistence. Records are stored in local `.dat` files rather than a database.
